# Features

## Overview
Intermediate architectural grouping containing all domain-specific UI feature modules of the Laqta studio workbench.

## Subdirectories & Boundaries
- [Clips](./clips/README.md): Candidate clip review and boundary tuning
- [Dashboard](./dashboard/README.md): Studio dashboard landing screen and engine status
- [Projects](./projects/README.md): Project workspace management and video upload
- [Rendering](./rendering/README.md): Render and export feature module
- [Studio](./studio/README.md): Shared studio workbench types and presets
- [Transcription](./transcription/README.md): Speech transcription viewer and launcher
- [Settings](./settings/README.md): Settings studio and BYOK credentials workbench
